# Neerija's OpenGL Engine
A deferred rendering engine made with OpenGL.
![Bloom Effect](report/screenshots/Screenshot_Bloom.png)
## Current Features
  - 3D Rendering
  - Model Loading
  - PBR Materials
    - Occlusion Mapping
  - HDR
  - Bloom
